# 时间线与分级地图工作流

## 顶层：游戏时间线

- 打开项目默认进入 **时间线无限画布**（`kind=timeline`）
- **大剧情节点**（`mapPortal`）表示一个地图入口，可连线表示剧情顺序/分支
- **双击**大剧情节点 → 进入对应地图 **摆点模式**
- 左栏「时间线大剧情」可拖动排序，同步 `tasks[]` 的 `mainlineStep`

## 分级地图（任意深度）

- 左栏 **地图分级** 树形展示：`parentGameMapId` 嵌套
- **+** 在当前地图下新建子地图（或根级新建）
- 面包屑：`时间线 / 父地图 / 子地图 / …`

## 地图内：NPC 与剧情

- **摆点**：从资源库添加 NPC（可同资源多摆点）
- **编剧情**：`npcEntry → … → npcExit` 链
- **子地图入口**：NPC 摆点设置 `subMapGameMapId`，双击该摆点下钻子地图

## 与旧版差异

| 旧                            | 新                                         |
| ----------------------------- | ------------------------------------------ |
| 全局任务列表 + quest 详情画布 | 时间线 `mapPortal` + 地图内 NPC 链         |
| 主线 mainline 画布            | 时间线连线 + `condition`/`questCheck` 门控 |
| 扁平地图管理                  | 无限深度地图树                             |

导出仍使用 `project.quests`（由时间线同步）生成各 `map_*.json` 的 `tasks[]`。
