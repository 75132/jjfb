机甲虫族回合制网游 · 地图架构&核心规则（修正版+主线链路）

一、游戏核心定位

游戏类型：长期在线2D回合制网游（非终结制）

核心玩法：机甲捕捉 + 回合制战斗 + 副本推图 + PVP

核心循环：四城声望/战力提升 → 探索高难度副本 → 获取资源/机甲部件 → 守卫/反击新威胁

最终目标：长期守卫人类防线，对抗虫族、机甲叛军及其他未知威胁（不终结虫族，保障长期可玩性）

二、主线链路（以城市为接口，扩散推进，必过所有普通副本）

核心规则：主线第一遍必须通关所有普通副本（精英副本不属于主线，为后期额外挑战）；莱温霍姆为迪卡城普通副本，是主线终章。

（一）第一站：测试基地（mapId: 0）【主线起点】

- 核心作用：新手教程、获取初始机甲、了解世界观（人类与虫族的对抗背景）

- 主线要求：完成新手教程，击退测试基地外围的少量虫族探子

- 主线衔接：通关后，解锁传送权限，前往法西城，开启主线正式流程

- 补充说明：无副本，仅作为新手过渡，不可遇敌

（二）第二站：法西城（mapId: 1）【主线第一阶段接口】

- 核心作用：主线任务承接、基础功能解锁（商店、机甲维修、社交）

- 主线要求：通关其附属普通副本——塔拉斯森林（3层），摧毁虫族在法西城外围的孵化点

- 副本关联：塔拉斯森林（普通循环副本·3层，难度递增），主线必过

- 主线衔接：通关塔拉斯森林后，解锁前往卡布雷萨的传送权限，推进至下一战区

（三）第三站：卡布雷萨（mapId: 2）【主线第二阶段接口】

- 核心作用：前线防线枢纽，承接主线任务，传递虫族动向情报

- 主线要求：依次通关其附属所有普通副本（均为3层，难度递增），清理虫族外围据点

- 副本关联（主线必过）：
        

  - 尼利亚荒原：清理虫族地面部队

  - 无尽森林：摧毁虫族隐藏的补给站

  - 雷奥斯：击退占据能源点的虫族集群

- 主线衔接：全部通关后，解锁前往埃塞克的传送权限，深入虫族控制区

（四）第四站：埃塞克（mapId: 3）【主线第三阶段接口】

- 核心作用：人类工业核心区，主线任务升级，解锁高阶机甲部件

- 主线要求：依次通关其附属所有普通副本（均为3层，难度递增），阻止虫族破坏工业设施

- 副本关联（主线必过）：
        

  - 兵工厂：夺回被虫族占领的机甲兵工厂，恢复生产

  - 魔虫洞：清理虫族地下巢穴，切断其补给通道

  - 安魂森林：净化被虫族污染的区域，解救被困人类

- 主线衔接：全部通关后，解锁前往迪卡城的传送权限，抵达前线决战区域

（五）第五站：迪卡城（mapId: 4）【主线终章接口】

- 核心作用：决战前沿，主线终章所在地，承接主线最终普通副本

- 主线要求：通关其附属普通副本——莱温霍姆（3层，难度最高的普通副本），完成主线终章任务

- 副本关联：
        

  - 莱温霍姆（普通循环副本·3层，主线终章）：主线必过，击败虫族前线指挥官，巩固人类最前沿防线

  - 伦卡空间站、潘多拉行星、月球遗迹、极北雪原（精英副本·3层）：不属于主线，为后期战力提升、获取稀有资源的额外挑战

- 主线衔接：通关莱温霍姆后，主线第一阶段完成，解锁长期守卫玩法（对抗虫族、机甲叛军），同时开放精英副本挑战权限

四、副本核心规则（统一规范）

（一）普通循环副本（主线必过，共7个）

包含：塔拉斯森林、尼利亚荒原、无尽森林、雷奥斯、兵工厂、魔虫洞、安魂森林、莱温霍姆（8个，均为主线必过）

- 层数：3层，每层难度递增（1层最简单，3层最难；莱温霍姆为难度最高的普通副本）
- 地图ID规则：虽然是3层副本，但**每一层都是独立地图**，即 1层/2层/3层各自拥有独立 `mapId` 与独立 `map_{mapId}.json`

- 刷新机制：每日刷新（打完次日重置，无法当日重复挑战）

- 遇敌规则：可遇敌，遇敌概率随层数提升，每层有专属敌人池

- 掉落奖励：机甲部件、升级材料、金币

- BOSS奖励：击败每层BOSS可获得专属礼盒（不直接掉落机甲）

（二）精英副本（不属于主线，后期挑战）

包含：伦卡空间站、潘多拉行星、月球遗迹、极北雪原

- 层数：3层，每层难度大幅提升（整体难度远高于普通副本）
- 地图ID规则：精英副本同样按“每层独立地图”处理，每层独立 `mapId`

- 刷新机制：每日刷新（打完次日重置）

- 遇敌规则：可遇敌，遇敌概率高，敌人强度远高于普通副本

- 掉落奖励：高级机甲核心、稀有升级材料、高阶道具

- BOSS奖励：击败每层BOSS可获得高级礼盒（不直接掉落机甲）

- 特点：挑战极限，用于后期战力保值、高阶资源获取，解锁条件为完成主线（通关莱温霍姆）

五、地图核心配置结构（与 README 版本统一）

一个地图一份 JSON 文件：`map_{mapId}.json`（例如 `map_1.json`）。

单文件结构：

map_{mapId}.json {
  mapId: number,          // 地图唯一ID
  mapName: string,        // 地图名称
  mapType: string,        // 地图类型（安全区/普通副本/精英副本/活动地图）
  canEncounter: boolean,  // 是否允许遇敌（安全区均为false）
  encounterRate: number,  // 遇敌概率（0~100，安全区为0）
  enemyIds: number[],     // 敌人ID池（安全区为空）
  npcs: [                 // 本地图内嵌NPC（不走全局NPC表）
    {
      npcUid: string,     // 地图内NPC唯一ID（建议 mapId_xxx）
      npcName: string,    // NPC名称
      prefabKey: string,  // NPC表现资源标识（可选）
      x: number,          // 坐标X（像素）
      y: number,          // 坐标Y（像素）
      events: [           // 统一事件模型（对话/战斗/传送等都在这里）
        {
          eventType: string,     // dialog(对话)/battle(战斗)/teleport(传送)/shop(商店)/task(任务)/capture(捉宠)/pvp(竞技)
          eventTypeDesc: string, // 中文备注（程序可忽略）
          eventParam: any,       // 事件参数（按eventType定义）
          order: number          // 执行优先级（越小越先）
        }
      ]
    }
  ],
  copyInfo: {             // 副本专属信息（安全区/活动地图无）
    copyType: string,     // 副本类型（普通/精英）
    dungeonId: number,    // 副本组ID（同一副本的1/2/3层共用）
    layer: number,        // 当前map对应的层号（1/2/3），注意每层都是独立mapId；用于层序解锁、难度倍率、奖励倍率与UI显示
    refreshTime: string,  // 刷新时间（每日04:00）
    isMainLine: boolean   // 是否主线必过（普通副本true，精英副本false）
  }
}

事件类型命名（统一）：
- dialog（对话）
- battle（战斗）
- teleport（传送）
- shop（商店）
- task（任务）
- capture（捉宠）
- pvp（竞技）

六、开发核心要求（给Cursor专用）

- 地图管理器（MapManager）需支持多城池架构，能识别玩家当前所在城池，校验跨城传送连通性，关联主线进度

- 支持副本分层机制：通关当前层（当前 `mapId`）后，解锁下一层对应的独立 `mapId` 传送权限；主线副本需校验“前一副本通关”才可解锁下一副本，记录玩家通关层数（存入数据库）

- 实现每日刷新逻辑：每日04:00重置所有副本的玩家通关进度，不影响主线解锁状态（主线副本解锁后永久有效，仅每日可重复挑战）

- 严格区分地图类型，安全区强制不可遇敌，副本按规则配置遇敌概率和敌人池；区分主线/非主线副本，精英副本需完成主线后才可解锁

- 所有传送逻辑需支持：城池间传送、城池到副本传送、副本层间传送；统一作为 NPC 事件处理（`eventType=teleport`），并校验对应副本/城池解锁进度

- 副本奖励逻辑：BOSS仅掉落礼盒，不直接掉落机甲，区分普通/精英副本礼盒等级；主线副本通关后可解锁对应城池传送权限
