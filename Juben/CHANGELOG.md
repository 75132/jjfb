# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

### Added

- Node-based local workspace storage service.
- Multi-target edge support from a single option handle.
- Battle enemy pools (`enemyIds`) with expression normalization.
- Python GUI helper for Windows local development.
- ESLint/Prettier/Vitest toolchain.
- CI workflow and contribution templates.

### Changed

- Editor UI labels and interaction cues improved for clarity.
- Persistence moved from browser storage to local Node API.
