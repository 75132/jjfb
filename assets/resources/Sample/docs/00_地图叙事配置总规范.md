# 地图叙事配置总规范（对齐 README + 剧情）

## 1. 总原则
- 一个地图一个 JSON：`map_{mapId}.json`
- 三层副本不是同图分层，而是三张独立地图（3 个 `mapId`）
- 所有交互统一挂在 `npcs[].events[]`，不再拆独立传送表
- `eventType` 用英文常量，额外保留 `eventTypeDesc` 中文备注便于策划阅读

## 2. 事件类型命名（统一）
- `dialog`（对话）
- `battle`（战斗）
- `teleport`（传送）
- `shop`（商店）
- `task`（任务）
- `capture`（捉宠）
- `pvp`（竞技）

## 3. 事件参数建议
- `dialog`：`dialogId`
- `battle`：`battleId`, `enemyGroupId`
- `teleport`：`toMapId`, `toX`, `toY`, `unlockKey?`
- `shop`：`shopId`
- `task`：`taskId`, `phase`（`accept`/`submit`）
- `capture`：`capturePoolId`, `captureRate`
- `pvp`：`roomType`, `ratingMin`, `ratingMax`

## 4. NPC 命名约定
- `npcUid`：`{mapId}_{role}_{index}`，如 `1_commander_01`
- `prefabKey`：优先复用旧资源命名（可参考 `tip/mapman.txt`）

## 5. 对话写作口径（结合原始提取）
- 主线风格：防线、虫族、机甲、补给、前哨、守卫
- 系统提示可复用：如“准备进入战斗”“任务已达成条件”“连接中，请稍等”
- 引导语可复用 `tip/hint@hint.txt` 中提示文本作为 NPC 常驻台词池

## 6. 三层副本字段建议
在地图 JSON 的 `copyInfo` 内保留：
- `dungeonId`：副本组 ID（1/2/3 层共用）
- `layer`：当前地图层号（1/2/3）
- `isMainLine`：是否主线必过
- `refreshTime`：每日刷新时间（如 `04:00`）
