# PVP 铁律 —— 从 MEMORY.md §6 迁出（2026-10-01）

> 机制设计原稿 `docs/PVP空窗挽回期机制设计.md`。

- **「空窗挽回期」**：无操作满 **5s** 才激活倒计时 → 归零**自动普攻**；每方满 **2 轮**转永久接管；**仅双方真人**时生效。
- 回合结算**必须主动推送**。
- ⚠ **载荷层级**：`push_to_user` 把业务包进 `data` → 消费方必须读 **`msg.data.state`**
  （读成 `msg.state` = `undefined` → **挂机方黑屏**）。
- PVP / PVE **共用表现层**。
- 「攻击次数」= **总段数**；**总伤上限恒 +20%** → 段数只影响打击感，不影响总量。
