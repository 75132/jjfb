# 普通副本（主线必过）三层地图配置稿

## 使用规则

- 每个副本拆 3 张地图：`L1/L2/L3` 分别独立 `mapId`
- 每层都配置独立 NPC 事件（任务、战斗、传送）
- 传送统一 `eventType=teleport`
- 循环副本每层固定 **3~4 个节点小任务 + 1 个 Boss 节点**
- 节点任务占比建议：**战斗 70%~80%**，**收集/击败收集 20%~30%**
- 每层流程建议：`节点1 -> 节点2 -> 节点3(可选节点4) -> Boss -> 传送下一层`

### 层内节点模板（通用）

- `node_1`：战斗节点（清理怪群）
- `node_2`：战斗节点（精英怪或机关战）
- `node_3`：收集节点（采集道具）或击败收集（打怪掉任务物品）
- `node_4`：可选战斗节点（挑战/加分/补给）
- `boss`：本层 Boss 节点（通关判定）
- `warp`：层间传送节点（击败 Boss 后解锁）

## 1) 塔拉斯森林（dungeonId: 101）

- L1：侦察清剿（建议 mapId: 1011）
- L2：孵化巢外围（建议 mapId: 1012）
- L3：孵化核心区（建议 mapId: 1013）

### 层内节点建议

- L1：3 节点 + Boss（战斗、战斗、收集、Boss）
- L2：4 节点 + Boss（战斗、战斗、击败收集、战斗、Boss）
- L3：3 节点 + Boss（战斗、收集、战斗、Boss）

### 关键 NPC（每层）

- `*_brief_01` 战前简报官（`dialog` + `task`）
- `*_battle_01` 虫群诱导点（`battle`）
- `*_warp_01` 层间传送员（`teleport`）

### 对话示例

- `该层虫群活动指数上升，先清外围再推核心。`
