## 五、技能等级（★ 本轮新增，来源 `Z_SkillLevel.js`）

### 5.1 规则

| 项 | 值 |
|---|---|
| 最高等级 | **Lv4** |
| 倍率 | `[1.0, 1.2, 1.3, 1.5]` → Lv1 ×1.0 / Lv2 ×1.2 / Lv3 ×1.3 / Lv4 ×1.5 |
| 取整 | `Math.floor(baseDamage × multiplier)` |
| 作用对象 | **伤害结果**（原插件在 `makeDamageValue` 里乘算）；治疗 / 护盾等非伤害效果原插件未定义，本工程可后续开启 |
| 记录粒度 | **每个机甲对每个技能独立记录等级** |

### 5.2 升级途径

| 途径 | 条件 |
|---|---|
| **自动升级** | 机甲升级时，逐个已学技能独立判定；概率 = `悟性 / 100 × 0.1` → 悟性 40~100 时 **4%~10%**；只有未满 Lv4 才判定 |
| **手动升级** | 花技能书 + 达到机甲等级 → Lv2 需 **1 本 + 25 级**；Lv3 需 **2 本 + 40 级**；Lv4 需 **3 本 + 50 级** |
| **★入口区分（2026-09-30 用户拍板）** | **背包「使用技能书」只用来「学会」**（`Skills` 字段没有该技能时才允许；已学会再用 → 提示「**已经学会，不能再学习了**」）。**升级只能在技能面板 UI 点「升级技能」**（走 `skill_level_up`，同样消耗技能书）。两条入口互不重叠，不再出现「一本书既能学又能升」。 |

> ⚠ **机甲初始 / 获得时技能为空**：`RobotPet` 文档里**连 `Skills` 字段都没有**，
> 只有用技能书学会才会写入（`$set` 自动创建 → 兼容旧玩家数据）。
> 因此**技能面板在新机甲上本来就是空的**，这是预期行为。

### 5.3 各类技能的等级开关

| 类别 | 自动升级 | 手动升级 | 数量 | 说明 |
|---|---|---|---|---|
| skill_1 主动攻击 / 辅助（29 个） | ✅ | ✅ | 29 | 都有技能书 |
| skill_3 自动触发（生命恢复 / 能量恢复） | ❌ | ❌ | 2 | 原工程技能 29 不在 `SKILL_BOOK_MAP` → 不可升；要开启需你点头 |
| skill_4 悟性（纳米攻击 / 弱点攻击） | ✅ | ❌ | 2 | ★2026-09-30 已补技能书 0090 / 0091 → 可用书**学会**；仍不开放用书升级（要开需你点头） |

> 数据字段：`lv_auto` / `lv_manual`（每技能），全局参数在 `skill_level` 块。

## 六、普通攻击：三职业三公式（★ 本轮新增，来源 `Z_GamePlay.js`）

原工程覆写了 `attackSkillId`：**装备枪械类武器（武器 id 28–51）时**，同一个普攻按钮按职业线打出不同公式。

| 职业线 | 用的技能 | 公式 | 前置条件 |
|---|---|---|---|
| 格斗 fighter | 默认普攻（RPG 技能 1） | `a.atk * 3 - b.def * 1 + 1000` | 无（不持枪也是它） |
| 射击 shooter | RPG 技能 11 | `a.atk * 2.5 - b.def * 1 + 1000` | **需持枪**（武器 id 28–51） |
| 全能 universal | RPG 技能 12 | `a.atk * 3.5 - b.def * 1 + 1200` | **需持枪**（武器 id 28–51） |

> 已写成 `server/data/Skills.json` 的 `normal_attack` 块（含 `gun_weapon_ids`、`class_field`）。
> 客户端已落成 `assets/Script/Game/SkillData.ts`：`resolveNormalAttack()` / `calcNormalAttackDamage()`
> （职业线判定 + 持枪判定 + 公式求值，52 项自测通过）。
>
> ⚠ **战斗伤害流程本轮未接管**（配置里 `normal_attack.enabled = false`）：原公式是「高倍率 + 大常数」
> （格斗 `atk×3 + 1000`），对应原工程数千属性；本工程 `Classes.json` 成长（lv1 MaxHP≈553、攻击≈355）
> 量级更小 —— 直接接管会让低等级普攻逼近一击必杀。**开启前需先定公式缩放口径。**
> 关闭状态下：服务端普攻仍为 `max(1, attack - defense)`，客户端表现不变。
> 另外原工程把技能 1 / 4 / 8 / 9 从技能列表里过滤掉（它们是内置普攻 / 进化技，不出现在技能栏）。
