# 宠物机甲升星概率计算说明

## 升星概率计算

### 计算公式
**源代码公式：** `Math.random() * 240 < this._growth`

**升星概率 = Growth / 240**

**规则：**
- 100成长值最幸运的情况下能到35星（不是硬上限，而是概率上限）
- 从1级到60级（59次等级提升），每次等级提升都会检查升星
- 100成长值 = 41.67%概率，59次机会，最幸运的情况下（每次都成功）能升59次星
- 实际中，100成长值最幸运能到35星左右

### 概率示例

| 成长值 (Growth) | 升星概率 | 说明 |
|----------------|---------|------|
| 50 | 20.83% | 默认成长值 |
| 60 | 25.00% |  |
| 70 | 29.17% |  |
| 80 | 33.33% |  |
| 90 | 37.50% |  |
| 100 | 41.67% | 最高成长值（最幸运能到35星） |

### 计算逻辑
- **每次等级提升时都会检查升星**（重要！）
- 如果一次升级跨越多个等级（如从1级直接升到10级），会对每个等级都检查一次升星
- 生成一个 0 到 240 之间的随机数：`Math.random() * 240`
- 如果随机数 < Growth，则升星成功
- 升星后星级 +1

### 重要说明
- **每个等级都会检查一次升星**，而不是每次升级只检查一次
- 例如：从1级升到60级，会检查59次升星（2级、3级、4级...60级各检查一次）
- 100成长值的机甲，每次等级提升的升星概率 = 100/240 = 41.67%
- 从1级到60级，59次机会，预期升星次数 = 59 × 0.4167 ≈ 24.6次
- 最幸运的情况下（每次都成功）能升59次星，但实际中100成长值最幸运能到35星左右
- **没有硬上限**，35星是概率上限（最幸运的情况）

## 升星属性加成计算

### 计算公式
根据参考代码：`rate = 0.02 - Math.random() * 0.01`

**每次升星的加成率范围：0.01 到 0.02（1% 到 2%）**

### 加成率分布
- **最小值**：0.01（1%）- 不包括此值，实际最小值为略大于 0.01
- **最大值**：0.02（2%）- 包括此值
- **平均值**：约 0.015（1.5%）

### 属性加成计算
每次升星时：
1. 生成一个随机的加成率 `rate`（0.01 到 0.02 之间）
2. 将此加成率存储到 `_star_bonus_rates` 列表中
3. 对每个基础属性应用加成：`bonus = base_value * rate`
4. 累计所有升星的加成

### 示例计算

假设一个机甲的基础属性：
- HP: 1000
- Melee: 120
- Accuracy: 110

**第1次升星**（假设随机率 = 0.015）：
- HP 加成：1000 * 0.015 = 15
- Melee 加成：120 * 0.015 = 1.8 → 1（向下取整）
- Accuracy 加成：110 * 0.015 = 1.65 → 1（向下取整）

**第2次升星**（假设随机率 = 0.018）：
- HP 加成：1000 * 0.018 = 18
- Melee 加成：120 * 0.018 = 2.16 → 2（向下取整）
- Accuracy 加成：110 * 0.018 = 1.98 → 1（向下取整）

**累计加成**（2星）：
- HP：15 + 18 = 33
- Melee：1 + 2 = 3
- Accuracy：1 + 1 = 2

## 实现细节

### 1. 升星检查（`check_star_growth`）
```python
if random.random() * 240 < growth:
    star_level += 1
    return True
```

### 2. 升星加成率生成（每次升星时）
```python
rate = 0.02 - random.random() * 0.01
# rate 范围：(0.01, 0.02]
```

### 3. 属性加成应用（`add_star_bonus`）
- 使用存储的 `_star_bonus_rates` 列表
- 对每次升星应用对应的随机加成率
- 累计所有升星的加成

### 4. 数据持久化
- `_star_bonus_rates` 列表保存在数据库中
- 确保每次计算时使用相同的加成率（保证一致性）

---

## 注意事项

1. **升星概率**：每次升级都会检查，不是每次升级都必定升星
2. **加成率随机性**：每次升星的加成率是随机的，但一旦生成就会保存
3. **属性计算顺序**：
   - 先计算基础属性（根据等级、成长值、悟性值）
   - 再应用升星加成
   - 最后应用独特成长值
4. **数据一致性**：升星加成率列表保存在数据库中，确保重新计算时使用相同的值
