# 图块工坊 · Tileset Studio

> **交接 / 二次开发**请看 **[`HANDOFF.md`](./HANDOFF.md)** —— 架构 · 数据契约 · 自测体系 · 改动指南 · 已知坑。

把**原始地图素材（图集 PNG / 整块地图碎片）**加工成一份新的图集：

* 按 48×48 **切格**，逐格可视化
* 逐格指定**语义**：地面 / 墙面 / 路面 / 可通行植物 / 不可通行物体 / 树冠(★上层)
* **整块贴**：框选一块 → 保持原样整块落下 / 平铺，**不拆散**（RPG Maker 手感）
* 一键生成**水平镜像 / 垂直翻转 / 180°** 变体 —— 一张图变四张，且每张都是完整的块
* **框选多少格就整块镜像多少格**；**只选中 1 格时才单独翻那一格**
* 图块可**复制**到多个槽位
* **撤回 / 重做**（多步历史栈）、**橡皮擦**（拖过即擦、点块内自动擦整块）
* **💾 存工程 / 📂 开工程**：把整个地图打成 **`.tsproj`**（就是个 zip：源图 + 五个槽的布局 + 语义 + 通行表 + 缩略图），随时导入还原
* 导出时自动产出**通行表 `flags`**（把「不可通行」真正写进 MV 数据，不再是口头约定）
* ★ **每个工程一个文件夹**：全部产物（包 + 各槽 PNG + flags + 清单）都进
  `桌面\图块工坊导出\<工程名>\` —— 不同地图不会混在一起
* ★ **导出绝不重名、绝不覆盖**：文件夹里已有同名文件时，自动改成 `-2`、`-3` …
  （反复导出会攒下历史版本，旧的那份一个字节都不会动）

## 启动

双击 **`start.bat`**，浏览器会自动打开 `http://127.0.0.1:19850/`。

关掉浏览器页面**不会**停止服务；停止请在黑色窗口里按 `Ctrl+C`。

> 端口被占用时会自动往后找（19851、19852 …），以窗口里打印的地址为准。

## 核心概念：**块**

> 你在左边框选出来的那个矩形，就是一个**块**。块会记住内部每一格的相对位置。

* 输出区里，**黄虚线框** = 一个完整的块；**亮黄实线框 + `BLOCK 7×6`** = 最近贴入的那块
* 块内没被选中的格子 = **空洞**，贴的时候保持原样不动（不会填空）
* 「补齐为矩形」按钮可以把散点选区补成完整矩形

### 两种放置方式（④ 区可切，快捷键 `G`）

| 方式 | 行为 | 用在哪 |
|---|---|---|
| **▦ 整块贴**（默认） | 保持框选形状原样落进空位；块与块按网格对齐排布 | 整块地图碎片、要做镜像的电竞/建筑块 |
| **▤ 逐个铺** | 每个格子依次填进空位，排成一行 | 一堆互不相干的独立图块 |

### 翻转口径：**按框选范围自动判定**（③ 区可强制切换）

在输出区**框选**出来的范围，就是一个「待翻转的整块」：

| 你的操作 | 行为 |
|---|---|
| **拖框选中多格**（默认） | **整块镜像** —— 每格自身翻转 **+ 格子排列一起反** → 出来就是**整块地图的镜像** |
| **只单击选中 1 格** | **只翻这一格** —— 适合微调单个图块 |
| ③ 区强制切到「只翻每格」 | 不管选多少格，都只翻每格、排列不动（做独立图块集时用） |

> 这是用户明确要求的口径：**框选 = 整块镜像；单选 = 单格翻转。** ③ 区按钮是给「批量只翻每格」留的后门。

> ⚠ **最容易误会的一点**（2026-10-01 用户问「有些我镜像为啥跟原图不一样」）：
> **「整块镜像」= 格子换位 + 每格翻转**。所以 2×2 框选按 H，是**左列 ↔ 右列对调**，
> 出来当然≠「原图」——它等于「把这块图整体左右翻过去」，这正是拼对称地形要的效果。
> 如果你要的是**每格自己翻、格子待在原位置**（做图块集：第 N 格必须还是第 N 格），
> 先把 ③ 区切到 **「只翻每格」** 再按 H/V/B。⑤ 区提示条会实时写明这次走的是哪一档。
>
> 另外变换是**叠加**的：同一格连按两次 H 会**翻回原图**（「点两次 = 没动」是设计如此，
> 不是丢效果）；要强制还原用 **原图** 按钮。

> ⚠ **第二个坑：① 区一片空白 ≠ 加载失败**（2026-10-01 用户报「地图素材加载失败」）。
> 早期版本默认打开**目录里排序第一张**图片，而 `地图素材\` 里排第一的是
> `bz.png`（240×48，只有 **5×1 格**）——看起来就像素材没加载出来。
> 现在改成：**优先 `map1*` → 否则格数最多的那张**，下拉里还按
> **地图（≥2×2 格）/ 零散素材（1×N 条状）** 分了组，并用**自然序**（map2 在 map10 前面）。
> 真加载失败时 ① 区顶上会**留红字**写清原因（不再只靠一闪而过的提示条）。

## 推荐工作流

### 场景 A：一整块地图 → 四个镜像版本（最常用）

1. 顶栏选 `制作进行素材 / 地图素材`，选 `map1_7x6.png`
2. 左侧点 **整张图当一块**（或按住左键拖出那块矩形）
3. ④ 区保持「**整块贴**」，点 **⚡ 一变四（保持块形）**
   → B 槽里出现 2×2 四块：原图 / 左右镜像 / 上下翻转 / 180°，每块都完整
4. 底栏 **保存本槽 PNG**

> 7×6 的块在 16×16 的 B 槽里刚好排 2×2；块大小会实时显示在 ④ 区（「B 可放 4 块 ✓ 4 变体放得下」）。

### 场景 B：在输出区刷块（RPG Maker 手感）

1. 左侧框好要用的块
2. 输出区鼠标切到 **🖌 刷块**（默认）
3. 在输出区**按住左键拖一个矩形** —— 松手时源块就**平铺**填进这个矩形
   * 拖得比块大 → 平铺重复；拖动中有半透明所见即所得预览
   * `Alt` + 拖动 = 临时切成框选
   * 左键单击 = 选中该格所在的**整块**（想选单格用 `Alt`）
   * 右键 = 删整块（`Alt`+右键 = 只删单格）

### 场景 C：给一批图块补镜像 / 翻转变体

1. 选图集 → ④ 区切成「▤ 逐个铺」
2. 左侧框选要变体的图块，打上语义标签
3. 点 **⚡ 一变四** → 每个源图块生成 4 张，依次填入
4. 256 格的槽位能装 **64 个源图块 × 4 种变换**，正好用满

### 场景 D：按语义分到 B / C / D / E 四个槽

1. 逐个框选打标签（地面→B、墙面→C、路面→D、植物/物体→E）
2. 点 **按语义自动分配槽位**
   → 自动落进对应槽；**同一个块不会被拆开**（混语义的块整体进 B），并提示有没有装不下的

### 场景 E：改错了 —— 撤回 / 重做

顶栏右侧有 **↩ 撤回** / **↪ 重做** 两个按钮，旁边显示还能退几步。

| 操作 | 快捷键 |
|---|---|
| 撤回 | `Ctrl+Z` |
| 重做 | `Ctrl+Y` 或 `Ctrl+Shift+Z` |

会进历史栈的动作：贴块 / 刷块 / 清空槽 / 删除 / 复制 / 整理 / 变换 / 打标签 / 按语义分配 / **橡皮擦**。
切槽、切素材、缩放**不会**进栈（避免历史被无意义动作冲掉）。栈深 60 步。

### 场景 F：擦掉不要的格子（橡皮擦）

输出区鼠标模式切到 **🧽 橡皮擦**（快捷键 `E`）：

* **按住左键拖** = 拖过哪格擦哪格
* **单击块内任意格** = 擦掉**整块**（和「整块贴」的手感一致）
* `Alt` + 点击 = 只擦这一格
* 擦错了 → `Ctrl+Z`

> 素材区的右键清标注不受影响；橡皮擦只管输出区。

## 快捷键

| 键 | 作用 |
|---|---|
| `1` – `6` | 给选中的素材格打语义标签（地面/墙面/路面/可通行植物/不可通行物体/树冠） |
| `0` | 清除标注 |
| `G` | 切换「整块贴 / 逐个铺」 |
| `E` | 切到 **橡皮擦** 鼠标模式 |
| `H` / `V` / `B` | 翻转选中的输出格：选多格 = **整块镜像**，选 1 格 = 只翻那格；都没选 → 最近贴入的整块 → 再没有就设置「放置变换」 |
| `空格` | 把选中的素材格放进输出槽 |
| `Ctrl+Z` | 撤回 |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 重做 |
| `Delete` | 删除选中的输出格 |
| `Esc` | 清空所有选择 |
| `Ctrl+A` | 全选素材格 |
| `Ctrl+S` | 保存当前槽 PNG |
| `Ctrl+Shift+S` | **存工程包 .tsproj**（源图 + 全部布局打包） |
| `Ctrl+O` | **导入工程包**（列出目录下的 .tsproj，点一下还原） |

鼠标：素材区 = 左键点选 / 拖动框选 / `Shift` 加选 / 右键清除标注；
输出区 = **刷块模式**左键拖=平铺、单击=选整块、右键=删整块；**框选模式**左键拖=框选（松手即成整块）、单击=单格、右键=删单格；**橡皮擦模式**左键拖=擦、单击=擦整块。`Alt` 随时临时反转「整块 / 单格」。

## 槽位容量（硬上限，来自 MV 引擎）

| 槽 | 格数 | 图片尺寸 | 说明 |
|---|---|---|---|
| A5 | 128 | 384×768 | 普通图块（8×16，比较窄） |
| B / C / D / E | 各 256 | 768×768 | 普通图块（16×16） |
| 合计 | **1152** | | 能放独立图块的全部格子 |

常见块的排布（16×16 槽）：

| 块尺寸 | 每行 | 每列 | 合计 |
|---|---|---|---|
| 7×6 | 2 | 2 | **4 块**（刚好一变四） |
| 8×7 | 2 | 2 | 4 块 |
| 4×4 | 4 | 4 | 16 块 |
| 3×2 | 5 | 8 | 40 块 |
| 16×16 | 1 | 1 | 1 块（放不下 4 个变体，用 A5 或分两次） |

> 导入的图如果只有 768×720（少一行 48px），本工具会按实际整格数算，导出时**一律补足到标称尺寸**（384×768 / 768×768），顺手解决「最后一行全是黑格」的老问题。

## 导出物

**导出根**默认 **`C:\Users\Administrator\Desktop\图块工坊导出\`**，但文件**不直接躺在这里** ——
每次导出都会先建（或复用）一个**以工程名命名的文件夹**，所有产物都进那个文件夹。

```
<导出根>\<工程名>\
```

> 底栏实时显示「导出根 ▸ 工程文件夹」，点「📂 打开导出目录」直接跳到那个工程文件夹
> （顺带帮你把它建出来）。想换导出根：底栏下拉，或服务端 `server.py` 顶部 `EXPORT_DIR`。

| 文件 | 内容 |
|---|---|
| `<工程名>_B.png` 等 | 各槽图集，标称尺寸（768×768 / 384×768），空位全透明；**空槽不导出** |
| `<工程名>_manifest.json` | 每格的来源（源图集 + 源格号）、变换、语义、通行性 + 完整 `flags` |
| `<工程名>_flags.json` | 8192 长的通行数组，可直接喂给 `Tilesets.json` |

★ **文件名前缀 = 工程名**（不是底栏那个「前缀」框 —— 那个只在「写进工程」时用）。

> 建议**先「💾 存工程」给地图起个名字，再导出**。没存过工程时会暂时拿源图名（`map1_7x6`）
> 当文件夹名，底栏会标「（未存工程）」；存一次工程，之后所有导出就都进你自己的工程文件夹了。

★ **绝不重名、绝不覆盖**：文件夹里已有同名文件时自动改成 `-2`、`-3` …
反复导出会攒下 `..._B.png` / `..._B-2.png` / `..._B-3.png`，**旧的那份一个字节都不会动**。
（想只要最新一份，自己删掉老的即可。）

> 「⚠ 写进工程 img/tilesets/」是唯一的例外：那边写进的是 RPG 工程，
> 文件名用**前缀框**里的名字、且**必须覆盖**（工程里引用的是固定文件名）。

**flags 约定**（MV 原生语义）：

```
0x0000  可通行
0x000F  四面不可通行   ← 「墙面」「不可通行物体」
0x0010  ★上层块        ← 「树冠」，盖住角色但不影响通行
```

底栏 **写进工程 img/tilesets/** 会把 PNG + 清单 + 通行表一起写进
`D:\机甲风暴开发素材合集\机甲风暴2\img\tilesets\`（同名文件会覆盖，会先弹确认）。

## 工程包 `.tsproj`（存地图 / 导入地图）

顶栏 **💾 存工程** 把「这一整张地图」打成一个**单文件**，
落到 `桌面\图块工坊导出\<工程名>\<工程名>.tsproj`（**工程名同时是文件夹名和包名**），
**📂 开工程** 列出来点一下就完整还原。本质上就是个 **zip**，把后缀改成 `.zip` 也能直接解压看。

```
桌面\图块工坊导出\我的沙洲城\      ← 存工程时自动建的同名文件夹
└── 我的沙洲城.tsproj            ← 一个文件，拷走 / 备份 / 发人都行
├── project.json     全部状态：五个槽的布局、每格的来源格号 / 变换 / 语义 / 块归属
├── source.png       原始素材图集（★原样拷进去，导入时不依赖原文件还在不在）
├── preview.png      当前槽缩略图（列表里好认）
├── flags.txt        8192 项通行表（人可读）
├── manifest.json    图块清单（tileId / 语义 / 来源 / 变换）
└── README.txt       说明：这张图是什么、怎么导回去
```

| 场景 | 操作 |
|---|---|
| 存一份 | `💾 存工程`（或 `Ctrl+Shift+S`）→ 输个名字 → **自动建一个同名文件夹**，包放进去 |
| 改完再存 | 再点一次，**覆盖同一个包**（默认名 = 源图名 + 时间戳，也可以自己起） |
| 导回来 | `📂 开工程`（或 `Ctrl+O`）→ 列表里点一张卡 → 源图 + 五个槽 + 标注全回来 |
| 源图丢了 | 没关系 —— 源图在包里，导入走包内的 `source.png` |
| 包是从别的机器来的 | 照样能开（源图自带，不依赖原路径） |
| **直接拖进来** | 把 `.tsproj` **拖到窗口上** = 导入（浏览器拿不到磁盘路径，走字节上传落到 `out/_drop/`） |
| 再存一份改样 | `Ctrl+Shift+S` = **另存**（弹名字，另起一个工程文件夹） |
| 两个地图都想留 | 起两个不同的工程名 → **两个文件夹**，各自的东西互不干扰 |
| 老包（裸放在导出根目录的） | 照样能在「📂 开工程」列表里看到、能导入（向后兼容） |

**导入会还原什么**：源图（含切格）、五个槽每一格的**来源格号 / 镜像翻转状态 / 语义标签 / 块归属**、
语义标注表、当前槽、整块贴 / 块翻转等设置。还原后画布**逐像素等于存之前**（自测 589824 像素 0 不符）。

> 导入是一次性整体替换，**不进撤回栈**（`Ctrl+Z` 不会退回到导入前的空白）。
> 中途换了新的素材图集，顶栏的「工程名」会自动清空（因为源已经不是那个包了）。

## 自测（全绿基线）

**推荐：一条命令跑完**（自己起服务、跑所有页面、跑复算、打总表）：

```bash
python _regress.py            # 全量（默认不碰桌面）
python _regress.py v4         # 只跑名字含关键字的项
python _regress.py 桌面        # 额外跑「真往桌面写」的链路（会在桌面留 7 个自测文件）
```

`_regress.py` 会依次跑：6 个 e2e 页面 → 4 条真写盘链路（存盘 + PIL 复算）→ 后端接口自测。

## 已知坑（踩过的，别再踩）

| 坑 | 现象 | 处理 |
|---|---|---|
| **canvas 预乘 alpha** | `drawImage → toDataURL` 往返后，`a=0` 的像素 RGB 被抹成 0 → 「导出 == 源」逐字节比对失败（但 alpha 完全一致） | 切格时就把全透明像素 RGB 归零；校验一律用「alpha 逐字节一致 **且** 归一化后逐字节一致」双口径 |
| **rAF 在后台标签页被暂停** | 切到别的标签页后，界面上的统计/清单一直不刷新 | `reqSrc`/`reqOut` 同时挂一个 `setTimeout` 兜底，谁先到用谁 |
| **`ImageData.data.buffer` 带 byteOffset** | `new Uint8ClampedArray(buf, 0, N)` 读出垃圾数据 | 用 `.slice(0, N)` |
| **768 宽画布取第 N 格** | 整段 `slice` 只能取第 1 格 | 按行 `(y*768+x)*4` 取 |
| **橡皮擦按「索引」写** | 鼠标链路传进来的是 **cell 对象**，函数却当索引用 → 擦不掉 | 统一 `eraseBlockAt(cellOrIdx)`，两种都收 |
| **撤回栈存引用** | 存浅拷贝 → 撤回后改一处，历史里的也跟着变 | 进栈一律**深快照**（`cell` 只存 `{src, tf, tag, blk}` 数据，不存 canvas） |
