### 记录下的关键口径（写文档时复核过代码，均为实测）
- 后端**无状态**，编辑状态全在前端 `S`；重启不丢（丢的是未存编辑，设计如此）。
- 零依赖 / 前端无构建 —— 接手后必须保持。
- `SLOT_BASE = {A5:1536,B:0,C:256,D:512,E:768}` → `tileId = base + index`（MV 分区，别乱改）。
- **兼容关键行**：`const pre = opt.prefix || (dir ? prefixName() : projFolderName())`
  —— 传了 `dir` = 老口径（前缀框，写 RPG 工程用，必须覆盖）；没传 = 新口径（工程文件夹 + 工程名 + noClobber）。
- `ensureProjDir()` 结果缓存在模块级 `PROJ_DIR`；`openSheetByPath / loadProject / setOutDir` 三处会 `PROJ_DIR = null`。
- 变换是**异或叠加**（连按两次 H 回原图，设计如此）；「整块镜像 = 换位 + 每格翻」是用户拍板口径，别当 bug 修。
- 回归基线 **531 项**（e2e 53+75+82+34+27、后端 48、链路 存盘/复算 1+26 / 1+23 / 48+27 / 49+37）。
- 写测试四条铁律：**不比「正好 N 个」**、**回归禁 `shutil.rmtree`**（撞安全删除拦截会静默卡死）、
  **`/api/list` 不列 .json**（用 `/api/info`）、**新页面必须挂进 `_regress.py`**。
