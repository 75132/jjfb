## 二、怪物全表字段含义（`monster@monster.txt`，解包）

每行 `@monster|@id=..|@occID=..|@name=..|@baseAtt=a,b,c,...|@downCZ=..|@upCZ=..|@downLW=..|@upLW=..|@monsterimgID=..|@nextJin=..|@jinLevel=..|@isRobot=..|@gifRel=..|@category=..`

- `@id`：怪物序号（0–501）
- `@occID`：职业/occ（-1=非机甲野怪；0=格斗系；1=射击系；2=全能系）
- `@name`：名称（含初/中/终 进化阶段）
- `@baseAtt`：**11~12 项基础属性**（映射已确认，见第三节；`raw_baseAtt` 原文留底可回算）
- `@downCZ/@upCZ/@downLW/@upLW`：成长/等级范围（CZ=成长? LW=?）
- `@monsterimgID`：立绘 ID，对应 gif 文件名里的数字（如 `139_1@monster14-铁臂｜初.gif` 的 `139`）
- `@nextJin`：进化到哪个 `@id`（-1=终态）
- `@jinLevel`：进化所需等级（25/45/50）
- `@isRobot`：**是否机甲（0/1）** → 决定立绘复用规则
- `@gifRel`：立绘相对路径（如 `普通机甲I/139_1@monster14-铁臂｜初.gif`）；**无此字段=单帧/需复用**
- `@category`：分类（普通机甲I/II、合成机甲I/II、虫族、顶级boss、其他）

## 三、baseAtt 字段映射（✅ 已由 occID×数值交叉验证确认）

| 1 | MP | MP / MaxMP |
| 2 | 格斗 | Melee |
| 3 | 射击 | Shooting |
| 4 | 护甲 | Armor |

## 五、立绘资源移植规则（gif 拆帧 / 单帧 / 同立绘复制）

资源目录（仿照 Robot 现有结构）：
- 帧：`assets/resources/Monster/{拼音key}_L{n}-{k}.png` + 同名 `.meta`（命名规则见**第十三节**）
- 动画（**双写**）：
  - `assets/Image/Monster/ani/{AniID}.anim` + `.anim.meta`（编辑器挂载用）
  - `assets/resources/Monster/ani/{AniID}.anim` + `.anim.meta`（**运行时 `resources.load` 只能读 resources 目录**，RobotShow 动态加载靠这份）
  - `.anim.meta` 格式：`ver 2.0.4` / `importer: animation-clip` / `userData.name = AniID`，每份独立 uuid
- `AniID == 帧前缀 == {拼音key}_L{n}`（如 `枯骨魔龙 → kgml_L1`）；临时机甲例外：帧 `temp_L1-*` / AniID `mon_temp_L1`。

规则：
1. **有 `@gifRel`** → 拆 gif 为 N 帧 png，按帧生成 `.meta`（含 uuid + trim 计算），再生成 `.anim`（引用各帧 `@f9941`，均匀 times）。
2. **无 `@gifRel` 但 `isRobot=1` 且 cocos 已有同立绘** → 复制 `assets/resources/Robot` 对应帧 + `assets/Image/Robot/ani` 对应 ani 到 Monster 目录（用户："野生机甲和非野生同一个立绘就复制过来用"）。
3. **无 `@gifRel` 且无现成立绘** → 用素材合集 `monster/*.png` 单帧（按 monsterimgID 映射）或占位，标注待补。

> cocos `.meta` 必须预先生成并固定 uuid（否则 ani 引用的 `@f9941` 无法对应）。`.meta` 结构参照 `assets/resources/Robot/amc_L1-0.png.meta`。

## 十三、命名规则：中文名 → 拼音首字母（2026-09-28 用户指定）

用户要求：**"文件名格式改为中文名称的所有字首字拼音来，比如，枯骨魔龙就是 kgml；如果后面有符号加英文，那就保持；重复的那就后加 _2"**。

### 规则实现（`monster_port.py`）
| 输入 | 处理 | 结果 |
|------|------|------|
| 中文字符 | 取拼音首字母（`pypinyin.lazy_pinyin`，缺失时回退 GB2312 区位码表，零依赖兜底） | 枯骨魔龙 → `kgml` |
| ASCII 字母/数字 | 原样保留并小写 | 山猫-RT → `smrt`；多普-I-S3 → `dpis3` |
| 符号 `·` `-` `｜` 空格 | 丢弃 | 卡罗·射击G型 → `klsjgx` |
| 罗马数字 Ⅰ/Ⅱ/Ⅲ | 先 NFKC 归一为 I/II/III 后按英文保留 | 野马Ⅲ → `ymiii`；蝙蝠Ⅳ号 → `bfivh` |
| `\| 阶段` 后缀（初/中/终） | 截断，不改缩写（阶段由 `_L1/_L2/_L3` 表达） | 铁臂\|初 → `tb` → `tb_L1` |
