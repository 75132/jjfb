### 环境与延迟（必读）

- **MongoDB 位置**：`ws_server.py` 通过环境变量 **`MONGO_URL`** 连接数据库；生产环境 **Mongo 应与游戏 WS 同区域或同机内网**，否则单次路由多次 Mongo 往返会被公网 RTT 放大，表现为机甲列表 / `world_enter` 等延迟与客户端超时。
- **本地开发**：建议在终端设置 `MONGO_URL` 指向 **本机或局域网 Mongo**，勿依赖编辑器直连远端云库做玩法测试（延迟与队头阻塞会被误判为「客户端卡顿」）。
- **路由耗时日志**：关键路由超过阈值时，`router.py` 会打 **`路由耗时偏高`**（含 `duration_ms`）；配合现有 **`慢请求检测`** 日志可对齐客户端 `request` 超时（验收：少发 408、少出现 request_id 不匹配刷屏）。
