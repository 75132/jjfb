# 物品效果系统文档

## 概述

物品效果系统用于处理物品使用后的各种效果，如增加经验、恢复HP/MP、获得物品、获得机甲等。系统采用配置驱动的方式，通过 `Items.json` 中的 `effect` 字段定义物品效果。

---

## 快速开始

### 1. 配置物品效果

在 `Items.json` 中为物品添加 `effect` 字段：

```json
{
  "id": 202,
  "name": "大经验包",
  "effect": "EXP:50000",
  "UsageTarget": "Player"
}
```

#### 根据ID批量更新
```bash
python server/tools/batch_update_items.py --by-id 202 203 204 --effect "EXP:50000"
```

```bash
python server/tools/batch_update_items.py --by-name "生命药水" "大生命药水" --effect "HP:1000"
```

#### 根据名称模式批量更新

## 效果类型（详细说明）

### 1. 玩家经验 (EXP)

**格式**: `EXP:数值`

**说明**: 增加玩家经验值，会自动计算升级

**示例**:
```json
{
  "id": 202,
  "name": "大经验包",
  "effect": "EXP:50000",
  "UsageTarget": "Player"
}
```

**效果**: 玩家获得 50000 经验，如果升级会显示升级信息

---

### 2. 玩家HP (HP)

**格式**: `HP:数值` 或 `HP:百分比%`

**说明**: 恢复玩家生命值

**示例**:
```json
{
  "id": 203,
  "name": "生命药水",
  "effect": "HP:1000",
  "UsageTarget": "Player"
}
```

或百分比恢复：
```json
{
  "id": 204,
  "name": "全恢复药水",
  "effect": "HP:100%",
  "UsageTarget": "Player"
}
```

**效果**: 
- `HP:1000` - 恢复 1000 点HP
- `HP:100%` - 恢复满HP

---

### 3. 玩家MP (MP)

**格式**: `MP:数值` 或 `MP:百分比%`

**说明**: 恢复玩家魔法值

**示例**:
```json
{
  "id": 205,
  "name": "魔法药水",
  "effect": "MP:500",
  "UsageTarget": "Player"
}
```

---

### 4. 机甲经验 (PET_EXP)

**格式**: `PET_EXP:数值`

**说明**: 增加机甲经验值，会自动计算升级和升星

**示例**:
```json
{
  "id": 206,
  "name": "机甲经验包",
  "effect": "PET_EXP:100000",
  "UsageTarget": "Pet"
}
```

**注意**: 必须指定 `UsageTarget: "Pet"`，使用时会要求选择机甲

---

### 5. 机甲HP (PET_HP)

**格式**: `PET_HP:数值` 或 `PET_HP:百分比%`

**说明**: 恢复机甲生命值

**示例**:
```json
{
  "id": 1,
  "name": "初级修理包",
  "effect": "PET_HP:500",
  "UsageTarget": "Pet"
}
```

或百分比恢复：
```json
{
  "id": 2,
  "name": "中级修理包",
  "effect": "PET_HP:50%",
  "UsageTarget": "Pet"
}
```

---

### 6. 机甲MP (PET_MP)

**格式**: `PET_MP:数值` 或 `PET_MP:百分比%`

**说明**: 恢复机甲魔法值

**示例**:
```json
{
  "id": 207,
  "name": "机甲能量包",
  "effect": "PET_MP:300",
  "UsageTarget": "Pet"
}
```

---

### 7. 获得指定物品 (ADD_ITEM)

**格式**: `ADD_ITEM:物品ID:数量`

**说明**: 使用后获得指定物品和数量

**示例**:
```json
{
  "id": 208,
  "name": "物品礼包",
  "effect": "ADD_ITEM:23:5",
  "UsageTarget": "Player"
}
```

**效果**: 获得物品ID为23的物品，数量为5个

**注意**: 
- 会自动处理物品堆叠（根据 `CanStack` 和 `StackLimit` 配置）
- 如果背包已满，可能会失败（需要扩展处理）

---

### 8. 获得随机物品 (ADD_RANDOM_ITEM)

**格式**: `ADD_RANDOM_ITEM:物品ID1,物品ID2,物品ID3:数量`

**说明**: 从指定物品列表中随机选择一个，获得指定数量

**示例**:
```json
{
  "id": 209,
  "name": "随机物品礼包",
  "effect": "ADD_RANDOM_ITEM:23,24,25:1",
  "UsageTarget": "Player"
}
```

**效果**: 随机从物品ID 23、24、25 中选择一个，获得1个

---

### 9. 获得随机机甲 (ADD_RANDOM_ROBOT)

**格式**: `ADD_RANDOM_ROBOT`

**说明**: 使用后随机获得一个机甲

**示例**:
```json
{
  "id": 210,
  "name": "机甲礼盒",
  "effect": "ADD_RANDOM_ROBOT",
  "UsageTarget": "Player"
}
```

**效果**: 从 `RobotBase` 集合中随机选择一个机甲，创建并添加到玩家机甲列表中

**注意**: 
- 机甲的成长值、悟性值等属性会随机生成
- 机甲等级初始为1级

---

### 10. 还原晶体 (PET_RESET)

**格式**: `PET_RESET`

**说明**: 将指定机甲还原为1级，使用 `RobotPet_backup` 备份恢复所有属性

**示例**:
```json
{
  "id": 57,
  "name": "还原晶体",
  "effect": "PET_RESET",
  "effecttext": "使用后将指定机甲还原为一级。",
  "UsageTarget": "Pet"
}
```

**效果**: 
- 将机甲等级还原为1级
- 经验值重置为0
- 从 `RobotPet_backup` 恢复所有属性（HP、MP、成长值、悟性等）
- 清除升星加成率和独特成长值

**注意**: 
- 必须指定 `UsageTarget: "Pet"`
- 机甲必须有 `RobotPet_backup` 备份数据，否则无法还原

---

### 11. 重生晶体 (PET_REBORN)

**格式**: `PET_REBORN`

**说明**: 将指定机甲还原为1级，随机刷新成长值、悟性值和基础属性

**示例**:
```json
{
  "id": 12,
  "name": "重生晶体",
  "effect": "PET_REBORN",
  "effecttext": "使目标机甲还原成为1级，所学技能与附加成长值将删除。刷新影响机甲的成长与悟性。",
  "UsageTarget": "Pet"
}
```

**效果**: 
- 将机甲等级还原为1级
- 经验值重置为0
- 重新随机生成成长值和悟性值（与创建机甲时相同的逻辑）
- 从 `RobotBase` 重新生成基础属性并随机化（±5%）
- 清除升星加成率
- 重新创建 `RobotPet_backup` 备份

**注意**: 
- 必须指定 `UsageTarget: "Pet"`
- 机甲必须有 `robot_base_id`，否则无法重生

## effecttext 字段说明

为了区分技术性的效果字符串和用户友好的描述文本，系统引入了 `effecttext` 字段：

- **`effect`**: 技术性效果字符串，用于服务器处理（如 `PET_EXP:100000`）
- **`effecttext`**: 用户友好的描述文本，用于客户端显示（如 `"机甲获得10万经验"`）

**示例**:
```json
{
  "id": 206,
  "name": "机甲经验包",
  "effect": "PET_EXP:100000",
  "effecttext": "机甲获得10万经验",
  "UsageTarget": "Pet"
}
```

**客户端显示**: 客户端会优先显示 `effecttext`，如果没有则显示 `effect`

## 组合效果

多个效果可以用 `|` 分隔，会依次应用：

```json
{
  "id": 211,
  "name": "全恢复药水",
  "effect": "HP:100%|MP:100%",
  "effecttext": "恢复满HP和MP",
  "UsageTarget": "Player"
}
```

**效果**: 先恢复满HP，再恢复满MP

## 批量修改 Items.json

使用提供的批量修改工具脚本（见 `tools/batch_update_items.py`）可以批量修改物品效果。

### 使用示例

```python
# 批量设置经验包
update_items_by_id([202, 203, 204], effect="EXP:50000")

# 批量设置HP恢复
update_items_by_name(["生命药水", "大生命药水"], effect="HP:1000")

# 批量设置机甲经验
update_items_by_pattern(name_pattern="机甲经验", effect="PET_EXP:100000")
```

## 注意事项

1. **服务器权威**: 所有效果计算都在服务器端完成，客户端只负责显示
2. **原子操作**: 效果应用失败时，物品不会被消耗
3. **错误处理**: 效果应用失败会返回详细错误信息
4. **数据验证**: 所有参数都会进行验证，无效参数会返回错误
5. **日志记录**: 所有效果应用都会记录日志，便于调试

## 常见问题

### Q: 如何让物品同时增加经验和HP？

A: 使用组合效果：`effect: "EXP:50000|HP:1000"`

### Q: 如何让物品恢复百分比HP？

A: 使用百分比格式：`effect: "HP:50%"` 或 `effect: "PET_HP:100%"`

### Q: 如何让物品获得多个随机物品？

A: 目前不支持一次获得多个随机物品，可以创建多个效果组合，或扩展 `ADD_RANDOM_ITEM` 支持数量参数

### Q: 如何添加新的效果类型？

A: 参考"扩展新效果类型"章节，添加处理器并更新文档
