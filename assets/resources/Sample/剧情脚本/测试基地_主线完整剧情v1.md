# 测试基地（mapId: 0）主线完整剧情脚本 v1

## 0. 剧情定位与核心设定
- 背景开场：虫族入侵升级，人类发布紧急征召令。
- 玩家身份：你是“自愿报名”的新兵，正在被带往测试基地报到。
- 关键事件：途中科研博士遭袭，你以护卫视角首次实战，击退虫族。
- 节奏目标：1 次护送战 -> 3 次对接战斗训练 -> 1 次结业战 -> 解锁法西城。
- 人物要求：测试基地共 4 名对接人物，其中 1 名为贯穿主线的统一接头人。

---

## 1. 角色与 NPC 对接
1. `0_lead_01` 接头人「韩诺中尉」（主线贯穿）
   - 职责：接引、发任务、串联四段流程、最终放行传送。
2. `0_doctor_01` 科研博士「凯尔博士」
   - 职责：遭袭目标、剧情核心受保护对象。
3. `0_instructor_01` 战训官「罗威教官」
   - 职责：基础战斗训练与结业战判定。
4. `0_engineer_01` 机甲技师「维塔」
   - 职责：机甲启封、技能调试、战斗前整备。

> 说明：四人都参与战斗对接（有战斗节点或战前/战后战斗任务提交）。

## 3. 分幕脚本（含选项文字）

## 幕一：征召途中（接头）
### 场景
- 地图：测试基地外环通道（剧情子区）
- 出场：韩诺中尉、玩家

### 对话
- 韩诺：`抬头看天，红警不是演习。虫族已经咬到外环了。`
- 韩诺：`最后问一遍——你是自愿来的，还是被热血冲昏了头？`
- 玩家（系统旁白）：`警报灯把夜色染成暗红，车队一路急行，路边是还没来得及清理的焦痕。`

### 玩家选项（必须弹窗）
- 标题：`是否确认加入机甲战斗队？`
- 选项A：`是，我签字，立刻报到`
- 选项B：`否，我想退出`

### 选项结果
- 选 A：
  - 韩诺：`行，名字我记下了。从现在起，你归我带。跟紧，别死在报到路上。`
  - 接任务：`taskId=100001`

### 玩家选项（战前确认）

  - 强制进入 `battleId=300001`

  - 机甲经验：`1200`

## 5. 事件落地建议（对接你的 JSON 结构）
- 对话：`eventType=dialog`
- 接取/提交：`eventType=task`（`phase=accept/submit`）
- 战斗：`eventType=battle`（`battleId` 对应上文）
- 传送：`eventType=teleport`（`toMapId=1`）

示例（简化）：
```json
{
  "npcUid": "0_lead_01",
  "npcName": "韩诺中尉",
  "events": [
    {
      "eventType": "dialog",
      "eventTypeDesc": "对话",
      "eventParam": { "dialogId": 10000101 },
      "order": 1
    },
    {
      "eventType": "task",
      "eventTypeDesc": "任务",
      "eventParam": { "taskId": 100001, "phase": "accept" },
      "order": 2
    },
    {
      "eventType": "teleport",
      "eventTypeDesc": "传送",
      "eventParam": { "toMapId": 1, "toX": 96, "toY": 144, "unlockKey": "clear_100005" },
      "order": 99
    }
  ]
}
```
