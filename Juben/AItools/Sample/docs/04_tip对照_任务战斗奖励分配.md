## 3. 普通副本分配（3 层 = 3 个 mapId）

### 统一节点规则（已加入循环副本）

- 每层固定：`3~4 个小任务节点 + 1 个 Boss 节点`
- 小任务节点结构：`战斗 -> 战斗 -> 收集/击败收集 -> (可选战斗)`
- 比例控制：战斗节点占大多数（约 70%~80%），收集类占少数（约 20%~30%）
- 通过条件：必须完成该层全部节点后，才可触发 Boss 与 `teleport` 下一层
